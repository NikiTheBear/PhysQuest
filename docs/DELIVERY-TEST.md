# 交付测试（DELIVERY TEST）

> 给学校交付前照这份清单过一遍。分 10 类场景，每一条按「做什么 → 期望看到什么 → 打勾」。
> 全过一遍大约一个下午。第一次在**开发机上**过，交付装机时再过一遍重点场景（标 🔴 的）。

## 环境

- 浏览器：Chrome / Edge 最新版，窗口 **≥ 1280px**（不支持手机端，这是设计决定）
- 两种运行方式都要测：
  | 方式 | 怎么起 | 特点 |
  |---|---|---|
  | A. 本地完整版 | 终端 1 `node scripts/run-platform.mjs`；终端 2 `cd apps/launcher && node src/server.mjs` | 实验台 + 各家 AI 都能用 |
  | B. 在线版 | https://wave-to-say-hi.github.io/PhysQuest/ | 只有直连 AI（OpenAI），实验台走静态版 |

---

## 1️⃣ 第一次打开（引导）

| 做什么 | 期望看到什么 | 结果 |
|---|---|---|
| 全新浏览器打开首页 | 顶部出现「✦ 第一次来？先看三分钟怎么用」，可一键打开教程页 | ☐ |
| 点教程里的「关掉」 | 引导条消失；刷新后不再出现 | ☐ |
| 从地址栏加 `?help=1` | 直接打开教程页（方便老师分享链接） | ☐ |
| 深链接 `?view=map` / `?view=quiz-bank` / `?view=report` | 分别直达知识地图 / 题库 / 报告页 | ☐ |
| 顶部「?」按钮 | 随时能再打开教程 | ☐ |

## 2️⃣ 配 AI 的 Key（多为可选功能，但老师课堂大概率用讲解）

| 做什么 | 期望看到什么 | 结果 |
|---|---|---|
| 顶部 ⚙ → 选 DeepSeek，填一个**错的** Key | 保存后试发一条，**报错是给老师看的正常话**（不是英文堆栈），且能改回来 | ☐ |
| 🔴 六大厂商各配一遍（DeepSeek / 通义千问 / Kimi / 智谱 / OpenAI / 自定义） | 除了 OpenAI（可直接连），其余提示「需要本地启动器」或走 127.0.0.1:8787 代理 | ☐ |
| 不配任何 Key | 整个学习流程不受影响；只 AI 讲解/（知识卡）AI 搭建用不了 | ☐ |
| 配错协议或地址给自定义厂商 | 失败提示说人话，Key 不会被偷偷清掉 | ☐ |
| Key 存哪里 | localStorage 或本地启动器配置，**服务器上没存任何 Key** | ☐ |

## 3️⃣ 🔴 完整走一遍九步（从知识地图到导出报告）

| 做什么 | 期望看到什么 | 结果 |
|---|---|---|
| 首页进「光学」模块 | 看到 22 个挑战、32 个知识点、32 张卡，数字与模块统计一致 | ☐ |
| 点一个挑战（如 CH-O2-01 让像和蜡烛一样大） | 进入挑战：先猜（三选一），**猜完提示锁定** | ☐ |
| 锁定后进了实验台 | 右侧「实验目标」区显示 goal + observation；说人话告诉学生该动哪个滑块 | ☐ |
| 拖物距滑块到 u=11.3、f=10、光屏 15 | 🔴 光屏上**没有**实线像；画面显示灰色虚线箭头 +「光屏在 15 cm，像在 87 cm —— 要挪到 87 cm 才能接住」 | ☐ |
| 把光屏挪到 15 cm → 再挪到 87 cm | 87 处出现绿色实线像，15 处是模糊光斑 | ☐ |
| 「我满意了」弹出满意度确认 | 填了理由才能下一步（认真程度闸门） | ☐ |
| 进入题库 → 做该挑战的几道题 | 每题答完立刻出「总解析 + 逐项解析」，错题被记进「踩过的坑」 | ☐ |
| 全部做完 → 报告页 | 报告能「生成」，渲染成标题+表格，不是一堆 `|` 号 | ☐ |
| 报告底部手写反思 → 导出 | 能导出成 `.md`，内容与屏幕一致；反思必须有本人手写，AI 不代写 | ☐ |

## 4️⃣ 题库

| 做什么 | 期望看到什么 | 结果 |
|---|---|---|
| 🔴 选题页搜「K-M2-06 压强」 | 能搜到该知识点，点击后看到属于它的题 | ☐ |
| 三个快捷入口（当前挑战 / 筛选里的全部 / 清空） | 各司其职，数量对得上 | ☐ |
| 做一道题：先选选项再提交 | **没选就提交按钮置灰**；答对选项轻微放大、答错左右晃动 | ☐ |
| 看逐项解析 | 每个选项（含正确的）都有一行「为什么对/错」 | ☐ |
| 简单→中等→困难三档 | 每档独立进度，做完一档自动提示进行下一档 | ☐ |
| 换个知识点再进来 | 之前做过的进度保留 | ☐ |

## 5️⃣ 报告闸门

| 做什么 | 期望看到什么 | 结果 |
|---|---|---|
| 🔴 一个挑战都没做想去报告 | 被拦：「先去完成一次挑战与题库」 | ☐ |
| 题没做完、反思写了 | 被拦：题干（或说得清哪一扇门没过） | ☐ |
| 题做完了、反思太短（< 10 字） | 被拦：提示反思要更具体 | ☐ |
| 两道闸都过 | 报告出现：模型声明 / 探索记录（预测 vs 实际表）/ 完成情况 / 踩过的坑 / 涉及知识点 / 反思 | ☐ |

## 6️⃣ 实验台

| 做什么 | 期望看到什么 | 结果 |
|---|---|---|
| 🔴 三种进法：从挑战进 / 从顶栏进（空白台）/ 从知识卡进（AI 帮搭） | 三种来源的初始状态正确（带目标 / 空台 / 已有器具） | ☐ |
| 顶栏「清空实验台」 | 有二次确认；确后工作台是空的 | ☐ |
| 「记录此刻」 | 当前参数存进学习记录；换参数后仍能对照 | ☐ |
| 「收起顶栏」 | 顶栏收起只剩退出按钮；再展开恢复 | ☐ |
| 运行/暂停/单步/重置 + 速度 0.1–4× | 物理照常跑；改时间倍率不重建仿真 | ☐ |
| 电路挑战（如串联）连好线 | 电流读数正常，断开某处报「电路：……」这样的正常话 | ☐ |
| 2D/3D 切换 | 画面正常切换，不白屏 | ☐ |

## 7️⃣ 重置

| 做什么 | 期望看到什么 | 结果 |
|---|---|---|
| 顶部 ⟲ → 只清学习进度 | 确认后：参数记录/预测/已完成/错题清空；**主题和 AI 设置还在** | ☐ |
| 顶部 ⟲ → 全部清空 | 连 AI Key 一起清掉，回到「第一次打开」的样子 | ☐ |
| 点完确认按钮再刷新 | 确认真生效（不是只清一半） | ☐ |

## 8️⃣ 三个主题

| 做什么 | 期望看到什么 | 结果 |
|---|---|---|
| 顶部 ☀ / ☾ / ◐（日/夜/跟随系统） | 三个都正确切换，**配色一致**（用同一套设计变量） | ☐ |
| 🔴 深色模式下过一遍五大页面（地图/挑战/实验台/题库/报告） | 没有「黑底黑字」或「白底白字」，光具座/光路这些图形在深色下也看得清 | ☐ |
| 跟随系统档：把系统切深/浅 | 页面跟着变，无需手动 | ☐ |
| 刷新页面 | 记住上一次选择的主题 | ☐ |

## 9️⃣ 断网（不配 Key）

| 做什么 | 期望看到什么 | 结果 |
|---|---|---|
| 🔴 断网状态下重新打开本地版 | 除「AI 讲解/搭建」外的全部功能可用：挑战、实验台、题库、报告 | ☐ |
| 断网时点 AI 讲解 | 提示说得清「没网/没 Key」，不是死在那 | ☐ |
| 离线时做实验、做题、写反思导出报告 | 全程不依赖网络 | ☐ |
| 在线版断网 | 站点加载不出来是正常的（在线版本来要走网络） | ☐ |

## 🔟 1280px 窄屏

| 做什么 | 期望看到什么 | 结果 |
|---|---|---|
| 窗口拉到 **1280×800** | 无横向滚动条（报告表格内部可横滚除外） | ☐ |
| 1280 宽看知识地图 176 张卡 | 网格排 3–4 列，卡片不互相压 | ☐ |
| 1280 宽进实验台 | 顶栏按钮不换行不溢出 | ☐ |
| 1280 宽做题库 | 左边知识点回顾 + 右边题目不挤 | ☐ |
| 更窄（< 1280） | 允许不好看，但不允许白屏/点击打不开（手机端明确不做） | ☐ |
