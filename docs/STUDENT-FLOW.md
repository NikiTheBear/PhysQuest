# 一次完整的学习，学生的每一步

> 这份是给团队看的：**学生在页面上到底按什么顺序点**，知识点在哪一步学。
> 看完你就能判断哪些环节还需要补东西。

## 逐步拆开说

### ① 打开网页

进到知识地图。上面只有三张模块卡，**只有凸透镜那张能点**。

另外两张是虚线的，写着「规划中」，点了没反应——这是故意的，让学生知道这个平台还长。

### ② 选模块

点「凸透镜成像」。

**这一步是整个流程的起点。** 没在这里选，后面的挑战和实验台都是空的，不会自己塞一个默认的给你。

### ③ 挑战导览：五个小目标

```
挑战 01  让像和蜡烛一样大
挑战 02  让像比蜡烛大三倍
挑战 03  让光屏上什么都没有     ← 多解，有三种做法
挑战 04  遮住透镜上半部分       ← 进阶，98% 的学生会猜错
挑战 05  看到那个接不住的像     ← 多解
```

**不是让学生"自由探索"，是给他一个小目标。** 自由拖滑块一分钟就看完了，有目标能玩十分钟。

### ④ 先猜（这是整个产品的核心）

点一个挑战，第一个弹出来的不是实验台，是一个问题：

> **先把蜡烛放在两倍焦距以外，再把光屏挪到像能清楚出现的地方。你猜屏上的像会是什么样？**
>
> A 倒立、比蜡烛小
> B 倒立、和蜡烛一样大
> C 正立、比蜡烛大

选完点「锁定我的猜测」，**这个答案就焊死了，改不了。**

> **为什么把猜测放最前面？**
> 因为人在猜错的那一刻才真正学到东西。光看别人演示，看完就忘；
> 先押注、被推翻，那个反差能记一辈子。

**知识卡在哪？** 就在这一步。如果学生没底，面板上有：

> ▸ 没把握？先看看相关的 3 张知识卡

点开就是这个挑战涉及的知识点，一张一张列出来：一句话结论、生活类比、为什么、最容易错在哪。

**不强制读，但随时能读。** 强制阅读就等于说明书，那正是我们想避开的。

### ⑤ 实验台：动手

这里左右两栏：

**左边**
- 一条物距-像距曲线，当前点有红点跟着走
- 公式 `1/u + 1/v = 1/f` 实时算给你看，拖哪个滑块哪个变量变蓝
- 三个滑块：物距 u、光屏位置、焦距 f
- 还有「遮住透镜上半」「换物体形状（箭头/F字/蜡烛）」
- 底下是**观察笔记**：三段色块显示你现在在一倍焦距内/一二倍之间/二倍以外，游标跟着滑

**右边**
- 光具座 + 三条特殊光线 + 光屏
- 光屏不在像的位置时，屏上是一团**模糊光斑**，不是「没像」
- 可以拖、可以滚轮缩放、可以全屏（全屏右下角还会补一根物距滑块）

学生在这里做的事是：**把参数调到能完成那个小目标**。

### ⑥ 我满意了：锁定

调到自己满意，点右上角「我满意了」。

弹出来问：
- 当前目标达成度多少（本地引擎算的，不打折）
- 给这次探索打几星
- 一句话说说为什么选这组参数

点「锁定这组参数」。**锁定了才算完成这次探索。**

### ⑦ 你猜的 vs 实际（这一下最值钱）

```
┌─────────────────┬─────────────────┐
│ 你的猜测          │ 物理引擎算出的    │
│ 倒立、和蜡烛一样大 │ 倒立、缩小的实像  │
└─────────────────┴─────────────────┘
```

猜错了会有一句：

> 实际答案是「倒立、比蜡烛小」。这个反差就是这次实验最值钱的地方——
> 你看一眼右边的光路图，找找是哪里和你的想法不同。

**注意：AI 不参与这一下。** 对比是纯本地算的，跟有没有配 Key 无关。

### ⑧ 测验与查漏补缺

四道题，从题库里按这个挑战的知识点挑。

答错的题会给一句「正确理解是……」，底下有个按钮「回去看相关的知识卡」。

**到这个阶段才会碰 AI**（如果配了 Key）。现在这版 AI 只会：
- 答疑（能看到你屏幕上的参数）
- 出题
- 下发参数指令（「把 u 调到 15」，你点了它才动）

### ⑨ 报告

最后一页：
- 左边写「我自己的结论」，**至少 10 个字才能出报告**
- 右边是探索记录表（每次锁定的参数和结果）

点「生成学习报告」，出来一份 `.md`，可以下载、可以复制。

**反思那栏明确没有「帮我写」按钮，AI 也不会替学生写。** 这是产品的道德底线。

## 所以「知识点在哪学」

三个地方，三个深度：

| 在哪 | 什么时候 | 学什么 |
|---|---|---|
| **预测面板里的折叠卡** | 猜之前没底的时候 | 一句话结论 + 类比 + 为什么 |
| **知识地图的知识点详情** | 平时想查、或者测验答错被推过去 | 完整：一句话 + 类比 + 为什么 + 易错 + 前置知识 |
| **实验台上拖滑块** | 全程 | 这个是「体感」，不是文字。拖十次比读十遍有用 |

**没有「先看十分钟知识卡再开始」这一步。** 这是刻意的。

光伏那个原型就是栽在这：一进门 800 字免责声明 + 四个教学目标 + 五步指南，学生还没摸到滑块就被劝退了。

---

## 一件事要你确认

现在这个流程里，**「知识点」和「挑战」是绑在一起的**：
你选的挑战决定了你能看到哪几张知识卡。

这可能有个问题：**如果学生只想学「u = f 不成像」这个知识点，他得先找到包含它的那个挑战（挑战 03「让光屏上什么都没有」）。**

替代方案是：**允许从知识地图直接进实验台**，跳过挑战和预测。现在代码里其实已经支持了（`openKnowledge`），只是入口藏在知识点详情弹层的「在实验台上看这个」按钮里。

两个选择：

**A. 保持现在这样**（挑战是主入口，知识点是辅助）
- 优点：每个学生都走完整的"先猜后做"，学习效果最好
- 缺点：想查某个具体知识点的人得绕一下

**B. 弱化挑战**（知识地图也能直接进实验台）
- 优点：自由度高，像查手册
- 缺点：学生会跳过"先猜"，那就变成了"看动画"，学习效果打折

我倾向 A。但这是产品判断，你说了算。
