## 七、几条不变的规矩

1. **物理由本地引擎算**，AI 只解释，不许自己编数字
2. **API Key 只存 localStorage 或本地启动器**，服务器零密钥
3. **AI 无特权**：只能下发参数，学生点了才动
4. **反思栏禁止 AI 代写**
5. **推送 GitHub 必须带代理**：`env http_proxy=http://127.0.0.1:7890 https_proxy=http://127.0.0.1:7890 git push`
6. 模型级别的标注要老实：可计算 / 近似 / 仅示意，**不许把「仅示意」说成「可以算」**
