# 五分钟上手

> 面向第一次打开的老师。跟着做一遍，就能把平台用起来。

## 1. 把网站打开（三选一）

| 方式 | 怎么做 | 适合 |
|---|---|---|
| 🖥 本地完整版 | 终端 1：`node scripts/run-platform.mjs`；终端 2：`cd apps/launcher && node src/server.mjs`，然后浏览器开 `http://127.0.0.1:4317` | 有实验台、能配任何 AI |
| ☁️ 在线版 | 浏览器打开 https://nikithebear.github.io/PhysQuest/ | 只想先看看、没有本地环境 |
| ⭐ 双击 | 双击 `start.command`（Mac） | 最简单，推荐装机用 |

> 最小窗口宽度 **1280px**。平板/手机上不好使，这是设计决定，不是 bug。

## 2. 认识五个地方（顶部从左到右）

```
知识地图 → 挑战导览 → 实验台 → 题库 → 我的报告
```

每个都是字面意思：先选知识点，再去做挑战（实验），做完去题库检验，最后生成个人报告。

## 3. 带一个学生走一遍（约 3 分钟）

1. **知识地图** → 点「光学」。看到 32 个知识点、22 个挑战。
2. 进「让像和蜡烛一样大」，学生先**猜**一个答案 → 系统锁定，不能改。
3. 工作台里拖「物距 u」的滑块，光屏上的像跟着变。
   - 让学生把 u 调到 11.3、f=10、光屏 15——看：光屏上没有像！文案会提示「像在 87 cm」。
   - 再挪光屏到 87，像一下子清楚了。**这一下「被打脸」就是记忆点。**
4. 学生觉得满意 → 点「我满意了」，填一句为什么 → 进题库。
5. 题库做完 → 「我的报告」自动生成：记录了他每一步参数、预测 vs 实际、踩过的坑。
6. 报告最后要求**本人手写反思**（AI 不代写）——这是设计：反思必须他自己写。

## 4. 三个最经典的演示点（实验课开场用）

| 演示 | 怎么调 | 学生会猜错成 | 事实 |
|---|---|---|---|
| 遮住透镜一半 | 打开光具座的「遮住上半部」 | 像只剩一半 | 像完整，只是变暗 |
| u = f（物距=焦距） | u 调到 10、f=10 | 成个巨大的像 | 不成像，出射光平行 |
| 物距小于焦距 | u=5、f=10 | 光屏上能接住 | 接不住，但能从透镜里看到虚像 |

> 这三个现象**不需要 AI、不需要网络**，断网都能演示。
