# 常见问题（FAQ）

## 打不开 / 进不去

**Q1 双击 start.command 没反应。**
Mac 首次双击会出现「无法打开，因为来自身份不明的开发者」——右键图标选「打开」再选一次即可。
Windows 看 `start.bat`。再不行，手动方式：终端里
`node scripts/run-platform.mjs` 起实验台服务、`cd apps/launcher && node src/server.mjs` 起代理，
再开浏览器访问 `http://127.0.0.1:4317`。

**Q2 网页打开了，但显示「Not Found / 无法访问」。**
本地版要两个服务都在跑（实验台 + 启动器）。只起了一个，网页能开但实验台用不了。
把两个终端都开着，别关。

**Q3 在线版 https://nikithebear.github.io/PhysQuest/ 打不开。**
在线版依赖网络，断网当然打不开（离线请用本地版）。如果网络正常还是打不开，看看是不是学校网关挡了 GitHub。

**Q4 平板/手机上能开吗？**
能打开，但**不推荐**：界面按 ≥1280px 设计，小屏会挤。交付硬件以「教室一台老师机 + 学生机/浏览器 ≥1280」为准。这是设计决定，不是 bug。

## 光屏上没像 / 像不对

**Q5 光屏上怎么也看不到像，是不是坏了？**
不是。先读光屏下方的文案——它已经把原因写出来了。最常见三种：
- 光屏放错位置：文案会说「像在 87 cm，要挪到 87 cm 才能接住」。
- u = f：不成像，出射光平行——文案会说「不成像」。
- u < f：虚像，光屏永远接不住——要从透镜里看。

**Q6 遮住透镜一半，怎么像没了一半？**
像**不会**剩一半。挡住一半只是变暗，位置大小都不变。这正是值得讲给学生听的反直觉点。像的位置由物距和焦距决定，跟通光面积无关。

**Q7 我调的数和老师不一样，像不同正常吗？**
正常。这是自由探究——不同参数当然不同结果。交作业（报告）说的是「你怎么想的、为什么」，不是「算对了没有」。

## 提交 / 报告

**Q8 报告点「生成」没反应，或按钮是灰的。**
报告有两道闸门，全过才能生成：
1. 本次挑战的**题库做完**（不是做一部分）；
2. **反思 ≥ 10 字**（必须本人手写，AI 不代写）。
灰着 = 还差某一扇，页面上会写清差哪个。

**Q9 报告想改？**
报告是「生成快照」，改不了历史——但你可以重做一遍挑战，新的探索记录会进新报告。反思想改：再填一次，报告按最新反思重新生成。

**Q10 怎么把报告交给老师？**
报告页有「复制」和导出 `.md`。复制后贴到 Word/文档，或用导出的文件交。里面「模型声明」说的是这台机器算了什么、没算什么，别删。

## AI 相关

**Q11 AI 用不了，是不是坏了？**
绝大多数功能**不需要 AI**。只有「AI 讲解」「AI 帮搭」用 AI。用不了先看：
- 配 Key 了吗（顶部 ⚙）？没配 = 没有 AI，其余照常。
- 是在线版吗？在线版浏览器只能直连 OpenAI，用 DeepSeek/千问/Kimi/智谱需要本地启动器。
- Key 填对没有？厂商页面生成 Key 时选对权限；填错会报「Key 无效」之类的人话，改了就行。
- 更多见《04-接AI（可选）》。

**Q12 担心学生拿 AI 抄答案？**
设计上已经防了：反思栏**没有 AI 按钮**（AI 不代写反思）；
先猜锁死必须在 AI 讲解之前；AI 只能做「解释你看到的读数」，物理数字全是本地引擎算的，不是 AI 编的。

## 数据与隐私

**Q13 学生数据存在哪？**
全部在**这台电脑**（浏览器 localStorage 或本地启动器目录），不上传任何服务器。
换学生：顶部 ⟲ →「只清学习进度」；整机移交：⟲ →「全部清空」（连 AI Key 一起清）。

**Q14 会连到外面传数据吗？**
学习流程（挑战、实验、题库、报告）完全本地算，断网可用。只有你主动用 AI 时，才会把「当前实验参数」发给你配好 Key 的那家厂商（用于讲解），学生不会把个人信息传出去。API Key 只存在本地钥匙串/localStorage，服务器零密钥。

## 内容与更新

**Q15 内容想改（加题 / 改文案）？**
仓库是开源的。改 `shared/knowledge-data/` 下的 JSON（知识卡、挑战、题库…）后跑
`node shared/knowledge-data/schema/validate.mjs` 自检（它会告诉你哪张卡缺字段）。
代码直接改，改完打标点 PR。不熟代码的，把要改的内容整理好发给改代码的同学即可。

**Q16 网页是旧版，没看到新功能？**
在线版随 GitHub 合并自动重新部署，等一两分钟刷新。本地版要重新 `git pull` + 重启两个终端。
