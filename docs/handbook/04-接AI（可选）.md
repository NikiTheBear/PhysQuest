# 接 AI（可选）

> 整个平台的核心学习流程**不需要 AI**：断网、不配 Key，照样能先猜、做实验、做题、出报告。
> 这套 AI 用来做两件锦上添花的事：**AI 讲解**（解释你看到的读数）、**AI 帮搭**（知识卡背面一键搭实验）。
> 不想折腾就跳过这份文档。

---

## 0. 先搞清楚两个概念

| 概念 | 是什么 | 影响 |
|---|---|---|
| Key | 你在这家 AI 厂商申请的一串密钥（`sk-...` / `ghp_...`），用来计费 | 没有 Key 就不叫 AI 厂商的服务器，AI 功能用不了 |
| 连接方式 | 平台访问厂商的方式 | 决定你在哪填 Key、能不能走通 |

平台有两种连接方式：

- **本地启动器（launcher）**：在本机 `127.0.0.1:8787` 起一个小代理，绕开浏览器跨域限制——**DeepSeek / 通义千问 / Kimi / 智谱 都要走它**。
- **浏览器直连**：只有 OpenAI 可以（且浏览器要求放行跨域）。

> 结论：想用 AI → 最稳的路径是「本地完整版 + 本地启动器 + 你申请来的 Key」。

---

## 1. 你需要什么

1. 一台能跑本地版的电脑（`node` + 两个终端）。
2. 一家厂商的 **API Key**（选一家就够，不用全配）。

## 2. 申请一个 Key（以 DeepSeek 为例，20 分钟）

1. 打开 https://platform.deepseek.com → 注册/登录。
2. 左侧「API Keys」→ 创建新 Key → 复制那串 `sk-...`（只显示一次，存好）。
3. 需要往账户里充一点钱（按量计费，课堂用量很低）。

> 国内选通义千问（阿里）也行：https://dashscope.aliyun.com → API-KEY 管理。
> Kimi（Moonshot）、智谱 GLM 同理，都是进各自开放平台申请。

## 3. 配对（本地版）

1. 起服务：终端 1 `node scripts/run-platform.mjs`；终端 2 `cd apps/launcher && node src/server.mjs`。
2. 浏览器开 `http://127.0.0.1:4317` → 右上角 **⚙**。
3. 「连接方式」选 **本地启动器**。
4. 厂商选 **DeepSeek**，把 Key 粘进去，保存。
5. 在 AI 面板里发一句话（比如「解释一下现在光屏为什么没像」）→ 能回话 = 通了。

> Key 存在 macOS 钥匙串 / localStorage——平台服务器不存 Key。
> 网址栏是 `127.0.0.1`（本机）时 Key 安全；**在线版会提示**哪些厂商需要本地服务。

## 4. 常见坑（照顺序查）

| 现象 | 先查 |
|---|---|
| 点发送没反应 / 转圈 | 两个终端都还开着吗？代理 8787 起来没？ |
| 报「Key 无效 / 401」 | Key 抄漏了、过期了，或这家的 Key 要带 `sk-` 前缀；去厂商后台重新生成 |
| 只有 OpenAI 能用 | 你用的是「浏览器直连」；换「本地启动器」，且本地版开的是 `127.0.0.1` |
| 报「跨域 / CORS」 | 说明走了直连但厂商不开直连——改用本地启动器 |
| 学校网挡了外网 | 部分厂商（DeepSeek 等）在国内可直连；OpenAI 需要能翻墙的链路，学校场景建议用国内厂商 |
| 「超出余额」 | 账户充值 / 用量看厂商后台 |

## 5. 安全提示

- Key = 花钱的钥匙。别截图发群里，别提交进仓库。
- 学生不该拿到 Key：老师一人配好，学生用「只清进度」重置时**保留** AI 设置即可。
- 平台请求只发「当前实验参数」给 AI 做讲解；不会把学生姓名等个人信息发出去。
- 不放心可以不给 Key——**不配 AI，平台 80% 的教学价值（先猜→做→被推翻→想明白）一样完整。**

## 6. 验收：配好以后试这 3 句

| 你发 | 期望 AI 回 |
|---|---|
| 「光屏现在在 15，像要挪到哪？」 | 回答里出现 87 cm 左右，解释比「挪一挪」具体 |
| 「遮住透镜一半，像为什么不剩一半？」 | 说出「像的位置由物距焦距决定、面积只影响亮度」 |
| 「我用 100 Ω 和 10 Ω 串联，哪个分压多？」 | 说出「电阻大的分压多」，最好带一句 U=IR |

答得出人话 = 配置没问题；答得物理错 = 那是厂商模型的问题，不是平台算错（平台的数字永远来自本地引擎，AI 只是解释员）。
