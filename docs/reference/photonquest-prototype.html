📖 光伏物理知识详解

每张卡片都按“学习目标 → 具体讲解 → 数字例子 → 常见误区 → 自测 → 实验”组织。建议按顺序阅读。

① 光子与带隙：先跨过能量门槛

你要学会：用光子能量和带隙判断一个光子在理想模型中能否被吸收。

光可以看成一个个光子。半导体中，价带里的电子获得足够能量后可以跃迁到导带，留下一个带正电的空穴，形成电子—空穴对。这里的“光电效应”是材料内部的光电激发，不是把电子打出电池表面。

光子能量：E = hc/λ
常用换算：E(eV) ≈ 1240 / λ(nm)
理想吸收条件：E ≥ Eg，等价于 λ ≤ 1240/Eg
具体例子：Eg = 1.55 eV
门槛波长 λg ≈ 1240/1.55 = 800 nm。
700 nm 光子能量约 1.77 eV ≥ 1.55 eV，理想模型中可被吸收；900 nm 光子约 1.38 eV < 1.55 eV，不能被用于跨带隙激发。
常见误区：“光越强，每个光子能量就越高”是错的。光强主要反映光子数量，光子的能量主要由波长决定。
自测：蓝光和红光，哪个单个光子能量更高？

蓝光。蓝光波长更短，由 E=hc/λ 可知单个光子能量更高。但这不代表蓝光电池效率一定更高，还要看吸收、热化和其他损失。

② 电子—空穴对与 PN 结：分开电荷才能输出

你要学会：解释“光产生了电子—空穴对，为什么还需要 PN 结”。

仅产生电子—空穴对还不够。如果它们很快复合，能量就会重新释放，无法持续输出。P 型与 N 型半导体接触后，交界处形成内建电场；在理想化描述中，它把光生电子推向 N 区、空穴推向 P 区，减少它们直接复合的机会。

光照：产生电子—空穴对
内建电场：分离并收集电荷
外电路：电子定向运动，对外做功
能量来源：太阳光，而不是 PN 结凭空供能
接上负载以后：电池并不是简单地“储存了一盒电子”。光持续提供能量，内建电场持续分离电荷，外电路形成电流。开路时没有持续外电流，但两端仍存在电压，这就是 Voc 讨论的状态。
模型边界：本页的 S–Q 模型把电荷收集理想化，不能用来模拟掺杂浓度、PN 结深度或内建电场分布。
自测：内建电场为什么不等于免费能源？

它只负责分离和引导电荷，输出能量来自入射光。撤掉光照后，PN 结本身不能持续向外供电。

③ 两类损失：带隙为什么不能太低或太高

你要学会：分别解释透射损失和热化损失，并理解效率峰值来自二者的权衡。

带隙太高：大量光子因 E<Eg 而无法激发电子，在本模型中直接透射。带隙越高，能利用的光子通常越少，Jsc 下降。
带隙太低：虽然更多光子能跨过门槛，但高能光子超出的那部分能量会很快转化为热，不能全部变成电输出。

热化例子：一个 2.00 eV 光子被 Eg=1.12 eV 的材料吸收，超出带隙的约 0.88 eV 首先面临热化损失，不能理解为整个 2.00 eV 都能输出。
透射例子：Eg=2.50 eV 时，λg≈496 nm；理想模型中，波长长于 496 nm 的光子不能跨带隙激发。
低 Eg：吸收光子多 → Jsc 倾向较大；热化和复合限制电压与输出
高 Eg：Voc 倾向较高；可吸收光子变少 → Jsc 下降
峰值：是“多吸收”和“少浪费”的权衡，不要求两种损失数值恰好相等
常见误区：“带隙越接近 0，吸收越多，所以效率越高”忽略了每个光子可输出的能量与电压限制。
自测：把 Eg 从 1.12 调到 2.50 eV，红色不可吸收区应怎样变化？

应变大。门槛波长从约 1107 nm 缩短到 496 nm，更多较长波长的光子落在不可吸收一侧，Jsc 会显著下降。

④ 读懂实验指标：效率不是“电流越大越好”

你要学会：看懂 Jsc、Voc、FF、η 的联系，并区分理论值、实际值和“百分点”。

Jsc（短路电流密度）：反映光生电流规模，单位 mA/cm²
Voc（开路电压）：外电路开路时的电压，受带隙和复合影响
FF（填充因子）：最大功率点接近“理想矩形”的程度
η（效率）：最大输出电功率 ÷ 入射光功率

电池输出功率同时取决于电流和电压，不能只看 Jsc。最大功率点满足 Pmax = Vmp × Jmp，而 FF = Pmax/(Voc×Jsc)。本页计算面板还给出 Vmp、Jmp 和能量损失，供你逐项核对。

具体读数：本模型中晶硅代表点约为 η=30.0%、Voc=0.88 V、Jsc=53.5 mA/cm²。这里是黑体太阳、300 K、仅辐射复合等假设下的理论极限，不是商业组件实测值。
单位提醒：从 30.0% 到 28.9% 是下降 1.1 个百分点，不是下降 1.1%。
常见误区：理论曲线峰值不等于真实产品的效率纪录，也不能单独证明某种材料在所有场景都最好。
自测：某方案 Jsc 很大，为什么 η 仍可能很低？

如果带隙很低，Voc 和最大功率点电压可能很小，同时热化等损失较大。功率由电压与电流共同决定，因此大电流不必然带来高效率。

初中路径：先观察门槛、电流和电压，再用两类损失解释效率峰值。

  1. 点击 0.70 eV：记录 Jsc、Voc、理论效率，观察吸收门槛和吸收后未输出损失。
