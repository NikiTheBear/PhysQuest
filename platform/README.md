# PhysQuest × Fieldlab · 物理仿真平台

PhysQuest 知识地图与知识卡 + Fieldlab 自由搭建物理平台。首次打开自动载入第一个原版实验；已有空间恢复上次编辑内容。原版 5 个实验保存为 `.pqexp.json`，载入即成为人和 AI 都能编辑的副本。新建空间仍为空白。

## 使用

- 在线版：部署后的 Site，默认私有。实验文档按用户隔离，MCP 与网页读写同一份文档。
- 单文件版：构建后打开 `standalone/fieldlab.html`，不需要联网或安装依赖。2D、3D、数值求解、器具编辑与导出均可用；数据保存在浏览器中。MCP 需要在线版或本地服务。
- 源码版：Node.js 22+，在本目录执行：

```sh
npm run install:ci
npm run build
npm test
npm run dev
```

本地地址 `http://127.0.0.1:4317/`，MCP 端点 `http://127.0.0.1:4317/mcp`。服务仅监听回环地址，本地开发身份固定为 `local-user`，文件保存在 `.local/`。不要将开发服务器直接暴露到公网。发布后的 Worker 不提供开发身份，必须有 Sites 注入的已验证用户身份。

构建会将前端、Three.js 和 Cannon-es 完整打包进 Worker，不依赖运行时 CDN，同时生成独立 HTML。修改源码后重新构建，刷新网页即可。

## 功能

- 白色工作台、器具库、属性面板与弹窗。点击物体后，3D 显示 X/Y/Z 坐标轴箭头，拖动沿对应轴移动并保存；2D 显示 X/Y 箭头，也支持直接拖动、缩放。
- 44 类基础器具，覆盖力、声、光、电、磁、电路与测量。力学包含球体、长方体、固定支点、弹簧、柔性绳索、刚性连杆、阻尼器、可调斜面、力 / 力矩源。
- 电路包含直流电源、电阻、电容、电感、开关、灯泡、电压表、电流表、参考地。点击 A/B 端子接线，支持串并联、RC/RL 暂态、支路电压 / 电流 / 功率读数与曲线。仪表接法：电压表并联，电流表串联。
- 声压色场、电磁场向量、几何光线、运动轨迹；空间自由旋转、缩放。
- 新增圆柱滚轮、周期驱动器、弹簧测力计、匀强电场、条形磁铁、凹透镜、光阑、滤光片、指向性声源、滑动变阻器、交流源、恒流源、测距仪和运动传感器。
- 自定义器具：可制作单个参数化器具或包含 1–24 个部件的组合器具，保留相对位置、机械引用与内部连线。支持公开电路端子、公开参数映射、颜色、固定状态、编辑、导入/导出和反复放置。不执行 AI 提交的任意代码。
- 对象列表支持快速选择和聚焦；网格吸附为 0.1 m。方向键移动、Shift 加大步长、Alt 调整 Z、F 聚焦、Ctrl/⌘ D 复制。
- 撤销/重做保留当前页面最近 20 次工作区修改，包括一次完整 AI 操作；Ctrl/⌘ Z 撤销、Ctrl/⌘ Shift Z 重做。接收到其他窗口或 MCP 的外部修改后清空旧历史，避免误覆盖。刷新页面会清空撤销历史。
- 跨物理过程：信号电源或电路支路电流→音圈、机械振动→声源、机械位移→光强，可设置增益。电磁场按空间关系作用，弹簧、绳索、连杆和阻尼器选择两个端点，力源选择受力刚体。
- 可编辑目标、模式、重力、阻尼、碰撞、初始位置与速度；运行、暂停、单步、重置和 0.1–4 倍播放。
- 实时信号、机械能、传感器读数；保存多个自建空间；导入/导出 JSON；导出最近 15 秒采样 CSV；声源试听。
- 文档采用条件写入，避免浏览器和 AI 并发覆盖。冲突时浏览器下载当前修改草稿再同步远端。每 2.5 秒读取外部更新，编辑文本时暂缓同步。

## 内置 DeepSeek

在右侧「AI 对话 → 连接设置」中填写自己的 API Key，选择 DeepSeek Flash 或 DeepSeek V4 Pro，可开启深度思考。输入消息后点击「发送」，AI 会通过与 MCP 相同的工具制作器具、搭建连接、调整条件并运行数值验证。需要在线站点或 `npm run dev` 本地服务；离线单文件不提供远程 API 代理。

- 密钥只保留在当前页面，不写入 localStorage、R2、源码或聊天记录；刷新后需要重新填写，也可点击清除。服务端只向固定的官方 `https://api.deepseek.com/chat/completions` 转发。
- 发送后，任务、最近的对话和工具读取的工作区数据会传给 DeepSeek；费用由该 Key 对应的 DeepSeek 账户承担。
- AI 的变更先暂存在内存，最终回答完成后通过条件写入一次保存。超时、输出截断、上游错误或并发冲突不会提交暂存变更。页面显示工具执行记录和 token 用量。
- 每轮最多 8 次模型请求、24 次工具调用；过大的任务需要分步发送。浏览器对话仅保存在当前页面；已有器具和设计按原有规则持久化。
- 已用模拟上游响应测试完整工具链、身份校验、失败回滚、密钥不落盘和并发冲突。没有使用用户真实 Key 进行付费模型测试。

按 [DeepSeek Chat Completions 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/) 实现，模型名称以 [官方模型列表](https://api-docs.deepseek.com/quick_start/pricing/) 为准。

## 器具制作流程

网页通过「保存为器具」制作单个器具；「组合器具工坊」勾选场景部件，保存相对布局和内部连接。器具出现在「我的」分类，点击放入，右上角菜单可编辑或导出。

MCP / 内置 AI 的完整流程为：`list_instruments` → `design_component` 或 `design_assembly` → `instantiate_design`。组合设计的部件 `id` 只在该设计内使用，放置时会自动生成新 ID，并重建内部引用。`ports` 将公开端子名映射到 `{componentId, port}`；`bindings` 将公开参数名映射到 `{componentId, parameter}`。放置时可用 `parameters` 覆盖这些参数，返回的 `ports` 可用于与外部电路接线。

组合器具由支持的物理部件组成；不会自动成为一个刚体，运动关系需要通过弹簧、连杆等约束定义。场景中的副本独立于器具库，修改或移除设计不会改变已放置的部件。原版实验通过实验文件载入，不限制器具设计。

## MCP

在线版在 `.openai/hosting.json` 声明 `mcp` 能力。Sites 发布时为其创建私人插件；连接完成后，AI 可以直接调用。支持无状态 `POST /mcp`、`server/discover`（2026-07-28）、`tools/list`、`tools/call`。额外兼容旧客户端的 `initialize`（2025-11-25）与 `ping`。

| 工具 | 功能 |
| --- | --- |
| `get_workspace` | 读取空间、当前实验、器具、连接、目标、修订号 |
| `list_instruments` | 读取器具参数范围、单位、连接约束与自定义器具 |
| `create_experiment` | 创建完全空白的实验空间 |
| `activate_experiment` | 在网页打开已有空间 |
| `update_experiment` | 更改名称、目标、模式、环境 |
| `add_component` / `update_component` / `remove_component` | 创建、编辑和移除器具 |
| `connect_components` / `disconnect_components` | 创建与移除导线及换能连接（导线指定 sourcePort / targetPort） |
| `design_component` | 制作单个参数化器具，包含颜色与固定状态 |
| `design_assembly` | 制作多部件器具及其内部连线、公开端子和参数 |
| `instantiate_design` | 放置设计副本，重建 ID 和内部引用 |
| `update_design` / `remove_design` | 编辑或移除器具库中的设计 |
| `control_simulation` | 控制网页运行、暂停、重置 |
| `simulate_experiment` | 独立执行求解，返回样本、读数、位置和模型局限 |

本地只读检查：

```sh
curl http://127.0.0.1:4317/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
```

支持 Streamable HTTP 的本地 MCP 客户端可连接上述回环端点。在线版请使用 Sites 创建的插件，访问鉴权由平台提供。「AI 协作 → MCP 接入」用于查看服务、复制端点和任务文本；「DeepSeek 对话」通过你提供的 API Key 实际调用模型。两种入口共用器具定义、校验和求解器。

## 计算范围

这是**教学与探索用的集中参数模型**，不是有限元、电磁全波或 CFD 求解器。

- 机械：Cannon-es 刚体求解，球体 / 箱体 / 圆柱碰撞、接触摩擦、转动惯量、重力、恒力、周期力和力矩；固定斜面与地面。弹簧遵循胡克定律，柔性绳索只受拉，连杆限制中心间距，阻尼器抵抗相对速度。连接作用于物体中心；没有任意网格、铰链偏置、柔体或材料形变。
- 电路：节点电压法，理想导线合并节点；电源内阻、电压表 10 MΩ、电流表 1 mΩ。电容 / 电感采用后向 Euler；浮置网络自动选择参考节点。开关用高低电阻表示，灯泡为定值电阻且亮度随功率变化；滑动变阻器为两端可变电阻；交流源为正弦电压加直流偏置，恒流源带有限输出电阻。没有半导体、温度非线性、寄生参数或完整 SPICE 器件库。
- 电磁：库仑场（0.04 m 软化半径）、洛伦兹力、有限球形区域内匀强电 / 磁场；条形磁铁用软化磁偶极子表示，不含磁铁间机械吸引力；没有麦克斯韦全波、磁滞或涡流。
- 音圈：`m x'' + c x' + k x = B L I`，RK4；有效导线沿 Y 轴、运动限制在 X 轴，驱动力使用带符号的 Bz 分量。
- 声：球面波叠加，1 m 外按 1/r 衰减，指向性声源采用前向余弦幂次方向图，无房间反射或介质非线性。3D 波环是慢速示意；2D 声压色场按实际相位采样。
- 光：每束 5 条采样光线，近轴薄透镜、理想镜面和孔径探测；光线在各光源 XY 平面传播，支持 Z 偏移判定；负焦距凹透镜使光线发散，光阑按孔径遮挡、滤光片按透过率衰减；没有衍射、偏振与厚透镜。
- 换能连接为单向线性近似，没有完整能量回馈；电路驱动音圈不反向加载电路，光强与声压调制限制在 0–10 倍。
- 固定步长 1/480 s；实时记录 60 Hz / 最近 900 样本，高频声波图存在混叠。试听使用 Web Audio 音频采样率。
- 运动传感器的加速度读数为外力 / 质量，不含接触求解器的瞬时冲量；测距仪读取两器具中心距离。
- 机械能包含平动与转动动能、重力及线性弹性势能，不包含电磁能。2D 求解时将 Z 分量置零，配置中的原始 Z 值保留。修改物理条件重置时间。
- 每空间最多 64 个器具、128 个连接；最多 30 个空间、50 个自定义器具；单次 MCP 求解最多 20 秒、1200 样本。

## PhysQuest 整合

首页保留 PhysQuest 品牌、知识地图和知识卡；自由实验台位于 `/workbench`，嵌入后仍使用相同 `/api` 和 `/mcp`，云端用户数据不迁移、不清空。原项目代码快照与 MIT 许可在 `physquest/`，安装的独立 Git checkout 位于上级仓库（`codex/free-build-platform` 分支）。双击仓库根目录 `start.command` 可启动整合版。

实验文件在 `experiments/`，格式与 AI 调用见 `experiments/FORMAT.md`。MCP 共 23 个工具。原版光具座使用原始凸透镜计算，内部 cm 参数、外部 m 位置，示意图独立于其他光学器具；支持 2D/3D 显示、参数编辑和整体坐标轴拖动。

探索记录保存当前配置及真实测量值到浏览器，可添加观察并导出 JSON。切换知识页不会丢失编辑；实验台隐藏时暂停本页面的计算和音频，返回后继续。DeepSeek Key 仅保留当前页面会话，无真实 Key 时不执行付费 API 验证。

检查：`npm test`、`npm run test:physquest`（原版 12 条断言）、`npm run build`、`npm run validate`。本地 QA 数据通过 `FIELDLAB_DATA_DIR` 隔离。

## 知识地图与 DeepSeek 搭建

全部 140 个原规划知识点已写成可编辑提示词，可按可计算、近似/类比、概念示意筛选。点击“用 DeepSeek 搭建”会把提示词传入工作台；已有会话 Key 时开始调用 MCP 工具，没有 Key 时等待填写。每次新建独立空间，要求真实放置器具并验证最终配置，成功后保存提示词来源和模型范围。原有实验不被覆盖。

提示词来源、生成流程和 MCP 查询工具见 `prompts/README.md`；完整下载 `/prompts/knowledge-prompts.json`。这是知识点提示词覆盖，并不意味着所有主题都有真实物理求解器。

## 碰撞范围与交互

器具属性中的“碰撞范围”支持自动形状、自定义长方体、局部中心偏移和单器具开关，2D / 3D 以相同定义绘制线框和求解接触。蓝色表示启用、灰色表示停用；全局环境碰撞也须开启。刚体参与动态接触，其他支持的器具作为固定障碍物；场、驱动器、两端连接及音圈不提供独立碰撞箱。编辑时允许自由摆放，运行后产生机械阻挡；不会因此增加光学遮挡、电磁耦合或材料形变。偏置形状的转动惯量采用 Cannon 的近似。

`collider = {enabled, shape: "auto" | "box", size: [宽, 高, 深], offset: [x, y, z]}`，单位 m，size 为完整尺寸。碰撞定义随实验文件和自定义器具保存，MCP 的添加、编辑与器具设计工具可读取和修改。

滑块在每个动画帧合并输入并实时预览；松手才保存一次、生成一次撤销记录。右侧 AI 聊天栏采用独立滚动的消息气泡和固定底部输入框，可与器具属性切换，保留草稿、会话和执行记录，Enter 发送 / Shift+Enter 换行，中文输入法确认不会误发送。缺少 Key 时保留消息并打开连接设置。执行中锁定场景编辑，避免本页面与 AI 相互覆盖。

交互细节：2D 单击只选中器具，移动超过 3 px 才进入拖动并暂停；方向键位移按保存队列逐次累加。快速来回调节参数保留最后一次输入。AI 执行期间禁止鼠标与快捷键编辑，完成后恢复；聊天输入支持中文输入法、Shift + Enter 换行与失败草稿恢复。3D 碰撞线框复用几何体，参数变化时重建。

GitHub 版本不包含私人站点 ID。没有 `.openai/hosting.json` 时仍可构建并在本机启动；Sites 部署时由站点工具创建该文件。静态 Pages 构建使用 `npm run build:pages`，其 AI 功能需要另外启动完整平台服务。
